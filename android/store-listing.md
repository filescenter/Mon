# صفحة التطبيق على Google Play

نصوص جاهزة للصق في Play Console. راجعها قبل النشر.

## الاسم (30 حرفاً كحد أقصى)

```
الصدّيقة: مجالس وأدعية
```

## الوصف القصير (80 حرفاً كحد أقصى)

```
مواعيد المجالس الحسينية ودليل الحسينيات والمواكب، مع الأدعية وأوقات الصلاة.
```

## الوصف الكامل

```
الصدّيقة تطبيق يجمع لك ما تحتاجه من الخدمات الحسينية في مكان واحد، ويبدأ من منطقتك.

مواعيد المجالس
• مجالس منطقتك أولاً، مرتبة يوماً بيوم.
• تصفية حسب المدينة واليوم، ومجالس الرجال والنساء.
• صورة إعلان المجلس وموعده ومكانه والمشاركون فيه.
• زر تذكير يضيف الموعد إلى تقويم هاتفك.

الدليل
• صفحات للحسينيات والمواكب والرواديد والخطباء.
• وسائل التواصل والموقع على الخريطة.
• خدمات المواكب للزائرين: طعام، مبيت، طبابة.
• تابع الصفحات التي تهمك لتجدها في المفضلة.

المكتبة
• أدعية وزيارات وتعقيبات بخط واضح قابل للتكبير.
• تُحفظ على هاتفك للقراءة بدون إنترنت.
• وضع داكن مريح في الليل.

أدوات يومية
• أوقات الصلاة حسب مدينتك أو موقعك.
• بوصلة القبلة.
• مسبحة إلكترونية: تسبيح الزهراء (ع) والصلوات والاستغفار.
• التاريخ الهجري والمناسبات القادمة.

لأصحاب الحسينيات والمواكب
سجّل صفحتك مجاناً، وانشر مواعيد مجالسك من هاتفك.

لا يحتاج التطبيق إلى تسجيل، ولا يحتوي على أدوات تتبّع.
```

## التصنيف

- الفئة: Lifestyle (نمط الحياة).
- الوسوم المقترحة: الدين، التقويم.
- تصنيف المحتوى: أجب على الاستبيان؛ التطبيق لا يحتوي على عنف ولا محتوى حساس، والنتيجة المتوقعة "للجميع".

## الإعلانات

اختر **نعم، التطبيق يحتوي على إعلانات**: بوسترات المجالس تظهر عند فتح التطبيق.

## الصور

| الحقل | الملف | المقاس |
| --- | --- | --- |
| الأيقونة | `icon-512.png` | 512×512 |
| الصورة الرئيسية | `feature-graphic-1024x500.png` | 1024×500 |
| لقطات الهاتف | `screenshots/01..08` | 1080×1920 |

اللقطات المرفقة مأخوذة من بيانات تجريبية. استبدلها بلقطات من بيانات حقيقية قبل النشر العام.

## أمان البيانات (Data safety)

إجابات مقترحة حسب ما يفعله التطبيق فعلاً. راجعها مع سياسة الخصوصية.

| السؤال | الإجابة |
| --- | --- |
| هل يجمع التطبيق بيانات؟ | نعم |
| هل تُشفَّر أثناء النقل؟ | نعم (HTTPS) |
| هل يمكن للمستخدم طلب الحذف؟ | نعم، عبر التواصل مع الإدارة |
| الاسم، رقم الهاتف، البريد | تُجمع اختيارياً عند طلب تسجيل صفحة؛ لوظائف التطبيق؛ لا تُشارك |
| الصور | يرفعها أصحاب الصفحات وتُنشر علناً؛ لوظائف التطبيق |
| الموقع الجغرافي | لا يُجمع: يُستخدم على الهاتف فقط ولا يُرسل إلى الخادم |
| معرّفات الجهاز والإعلانات | لا تُجمع |
| مشاركة مع جهات أخرى | لا |

عدّادات مشاهدات الإعلانات أرقام إجمالية غير مرتبطة بمستخدم.

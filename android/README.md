# نشر تطبيق الصدّيقة على Google Play

التطبيق يُنشر على Google Play كـ **Trusted Web Activity (TWA)**: تطبيق أندرويد صغير يفتح
نسخة التطبيق الموجودة على خادمكم ملء الشاشة. أي تعديل على المودل يظهر للمستخدمين مباشرة
بدون رفع نسخة جديدة للمتجر.

> هذه الخطوات لم تُجرَّب من بيئة التطوير، لأن أدوات أندرويد غير متاحة فيها. جهة أودو
> (ملف التحقق وصفحة الخصوصية وملف manifest) مجرَّبة باختبارات آلية.

## ما تحتاجه قبل البدء

| المطلوب | ملاحظة |
| --- | --- |
| دومين نهائي عليه HTTPS والمودل منصَّب | الدومين يُثبَّت داخل التطبيق ولا يتغير بعد النشر |
| حساب Google Play Console باسم IB4Tech | 25 دولاراً مرة واحدة |
| حاسبة عليها Node.js (نسخة LTS) | ويندوز أو لينكس أو ماك |

**مهم عن نوع الحساب:** الحساب الشخصي الجديد يشترط اختباراً مغلقاً بـ 12 مختبِراً لمدة
14 يوماً متواصلة قبل السماح بالنشر العام. حساب المؤسسة معفى من ذلك لكنه يحتاج رقم D-U-N-S.

## القيم الثابتة

| الحقل | القيمة |
| --- | --- |
| Package ID | `com.ib4tech.siddiqa` (لا يتغير بعد أول رفع) |
| اسم التطبيق | الصدّيقة |
| عنوان البداية | `/app` |
| ملف manifest | `https://DOMAIN/app/manifest.webmanifest` |
| صفحة الخصوصية | `https://DOMAIN/app/page/privacy` |

## الخطوات

1. تثبيت أداة Bubblewrap من Google:

```bash
npm install -g @bubblewrap/cli
```

2. إنشاء مشروع أندرويد من ملف manifest (استبدل `DOMAIN` بالدومين):

```bash
bubblewrap init --manifest=https://DOMAIN/app/manifest.webmanifest
```

   - وافق على تنزيل JDK و Android SDK عندما يسأل.
   - Application ID: `com.ib4tech.siddiqa`
   - اقبل الاسم والألوان والأيقونات كما يقرأها من الملف.
   - عند سؤال مفتاح التوقيع أنشئ مفتاحاً جديداً بكلمة مرور قوية.

3. بناء الحزمة:

```bash
bubblewrap build
```

   الناتج `app-release-bundle.aab`، وهو الملف الذي يُرفع إلى المتجر.

4. **احفظ نسخة من ملف المفتاح `android.keystore` وكلمة مروره في مكان آمن ولا ترفعه إلى GitHub.**

5. في Play Console: أنشئ التطبيق، ارفع ملف `aab` إلى Internal testing، واملأ صفحة المتجر
   من [`store-listing.md`](store-listing.md).

6. ربط التطبيق بالموقع (بدونه يظهر شريط المتصفح أعلى التطبيق):
   - في Play Console افتح **Test and release > App integrity > App signing** وانسخ بصمة
     **SHA-256 certificate fingerprint**.
   - في أودو: الصدّيقة > الإعدادات > الإعدادات > **Google Play**، أدخل اسم الحزمة والبصمة.
     إذا جرّبت ملف APK موقَّعاً بمفتاحك المحلي أضف بصمته أيضاً، مفصولة بفاصلة.
   - تأكد أن اسم الحزمة يظهر في `https://DOMAIN/.well-known/assetlinks.json`.

7. نزّل التطبيق من رابط الاختبار وتأكد أنه يفتح ملء الشاشة بدون شريط العنوان.

8. شغّل الاختبار المغلق (12 مختبِراً، 14 يوماً) إذا كان الحساب شخصياً، ثم اطلب النشر العام.

## بديل بدون أدوات على الحاسبة

موقع [PWABuilder](https://www.pwabuilder.com) يولّد حزمة أندرويد من رابط التطبيق مباشرة.
استخدم نفس Package ID، وأكمل من الخطوة 5.

## تحديث التطبيق لاحقاً

- تعديلات الواجهة والمحتوى: تُرفع على الخادم فقط.
- تغيير الاسم أو الأيقونة أو الألوان: عدّل في أودو، ثم:

```bash
bubblewrap update
```

```bash
bubblewrap build
```

  وارفع ملف `aab` الجديد.
